# Nexus Rescue

ระบบประสานงานช่วยเหลือผู้ประสบภัย พัฒนาด้วย Next.js และ Supabase

## เริ่มต้นใช้งาน

อ่าน [คู่มือการติดตั้งและพัฒนาระบบ](./DEVELOPMENT_GUIDE.md) สำหรับข้อกำหนดของเครื่อง ขั้นตอนติดตั้ง และการตั้งค่าให้แอปเชื่อมต่อได้ทั้ง Supabase Local และ Supabase hosted

อ่าน [คู่มือรายละเอียดและขั้นตอนการพัฒนาระบบ](./SYSTEM_DEVELOPMENT_MANUAL.md) สำหรับภาพรวมสถาปัตยกรรม ความสามารถ พัฒนาการตามประวัติ Git และขั้นตอนพัฒนาตั้งแต่ต้นจนถึงปัจจุบัน

> **ข้อจำกัดที่ต้องทราบ:** migrations ใน `supabase/migrations` เป็นการเปลี่ยนแปลงต่อจาก schema เดิม ไม่ใช่ชุดสร้างฐานข้อมูลตั้งต้น การเริ่ม Supabase Local บนฐานข้อมูลว่างจึงยังไม่ทำให้ระบบพร้อมใช้งาน ส่วน Supabase hosted ต้องเป็น project ที่มี schema เข้ากับโค้ดและได้รับอนุญาตให้ใช้ คู่มือระบุข้อจำกัดนี้ไว้อย่างชัดเจน

## คำสั่งหลัก

```bash
npm ci
npm run dev
```

คำสั่งพัฒนาและทดสอบฐานข้อมูล Local ดูได้ในคู่มือ อย่านำ credentials หรือข้อมูลผู้ใช้จริงมาใส่ใน source code, prompt, ภาพหน้าจอ หรือเอกสารที่ส่งเผยแพร่
